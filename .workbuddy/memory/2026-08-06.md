## 修复 coin_news 监控程序报错 + 新增钉钉错误告警

### 问题根因（main.py）
1. **line 46 崩溃（TimeoutError）**：币安页面被 CloudFront WAF 拦截，返回 `403 ERROR: The request could not be satisfied`。
   根因是 Playwright **默认 User-Agent** 被识别为爬虫，且手动加 `sec-ch-ua`/`Upgrade-Insecure-Requests` 等额外 header 反而**触发**封锁。
   - 修复：浏览器 context 设置真实 UA（Chrome 124 macOS）+ `args=["--disable-blink-features=AutomationControlled"]` + `add_init_script` 隐藏 `navigator.webdriver`。**不要**加额外反爬 header。
2. **`.FeedList` 选择器失效**：币安 DOM 已移除 `.feed-layout-main .FeedList .feed-card` 中的 `.FeedList` 包裹层。
   - 修复：改为 `.feed-layout-main .feed-card`（已验证 25 个卡片、`.feed-content-text a`/`.author .create-time`/`.richtext-container` 均有效）。
3. **漏检隐患**：原逻辑只检查第一篇非置顶文章，若该帖时间戳为 `--`（官方账号偶发无相对时间），直接 return 导致漏检更新的帖。
   - 修复：先在个人主页收集前 5 篇候选链接，再逐篇进详情页校验「最近 N 分钟内 + 含关键词」，不符合则继续下一篇。
